# 🎮 HF Plays — Benchmark, Gaming & Hardware Insights

**HF Plays** is a personal web portal and content hub focused on **PC benchmarking, gaming performance, and hardware optimization tutorials**. It serves as a central platform for sharing real-world benchmark data, game guides, and hardware insights created by **Hilmi Fauzan**.

🚀 Key Features
📊 Comprehensive Hardware Benchmarks: Real-world testing across budget, integrated graphics, and dedicated desktop rigs (Ryzen 5 7430U, Celeron N4000, RX 6600 8GB, RX 580 2048SP, GT 1030).

🎬 YouTube & Playlist Integrations: Direct links to full gameplay archives and benchmark video series.

📬 Interactive Dual-Channel Contact Form: Instant message dispatch via native Email draft or WhatsApp API redirect.

🔒 Privacy-First Architecture: Interactive Privacy Policy modal and lightweight cookie consent banner using localStorage and sessionStorage (zero third-party ad tracking).

📱 Modern Glassmorphic Dark UI: Fully responsive layout built with Bootstrap 5 and customized modern dark styling.

🖥️ Sections Overview
• Navigation Bar – Smooth scroll navigation with Hardware Specs dropdown (links to TechPowerUp & Intel ARK).

• Hero Section – Tagline, official branding, and quick actions to YouTube, BenchmarkResult, and Discord.

• Quick Links Grid – Cards linking directly to YouTube, Instagram, TikTok, and Discord channels.

• Hardware Benchmarks – Categorized performance archives with "What is a Benchmark?" educational section.

• Tutorials – Step-by-step video guides for boosting FPS, PC building, and overlay benchmarking.

• About the Creator – Profile of Hilmi Fauzan (Content Creator & Web Developer) and social profile pills.

• Contact – Interactive custom dropdown form (Email & WhatsApp) and official channel links.

• Footer & Modal – Copyright info, quick navigation, and accessible Privacy Policy modal dialog.

⚙️ Technologies Used
HTML5 — Semantic structure & accessibility

CSS3 / Bootstrap 5.3 (Dark Theme) — Responsive grid & glassmorphism components

Font Awesome 6 & Google Fonts (Inter) — Icons & modern typography
